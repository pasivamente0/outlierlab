Conectar la API de YouTube

Pega una clave de YouTube Data API v3 (Google Cloud Console → APIs y servicios → Credenciales). Se guarda solo en este navegador. Cada canal analizado gasta unas 4 unidades de cuota y cada búsqueda de nicho unas 102, de las 10.000 diarias gratuitas.
